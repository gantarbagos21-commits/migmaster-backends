5Auto Detect Vote-Kick

APK logic
60000 ms
Dimulai saat ID mendeteksi kick
Menunggu deteksi kick di room60000 ms
Aturan APK: setelah join, backend membaca event room.text dari WebSocket dan hanya mencocokkan pesan dengan sender room yang berisi A vote to kick. Timer dapat dimulai otomatis saat deteksi atau manual dengan Start Timer. Timer berjalan dari 60000 ms, dapat dihentikan dengan Stop Timer, lalu Kick All otomatis dijalankan saat sisa timer mencapai ambang. ACK room.kick.queued dari queue sendiri tidak dianggap sebagai deteksi.
